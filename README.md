# calculator-unit-converter


**Project:** Menu-Driven Calculator and Unit Converter

I created a Python command-line application that performs addition, subtraction, multiplication, and division. It also converts kilometers to miles, Celsius to Fahrenheit, and kilograms to pounds.

The program uses functions, `while` loops, `if/elif` statements, input validation, and exception handling. It also prevents division by zero and continues running until the user chooses to quit.

**Conversions added:**
- Kilometers to miles
- Celsius to Fahrenheit
- Kilograms to pounds
